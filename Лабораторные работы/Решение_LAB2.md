# Решение Лабораторная работа №2 "Оценка и коррекция траектории БПЛА по визуальным меткам ArUco"

## Описание решения

Студенту нужно будет самому запускать файлы полетных миссий в среде газебо, работать с терминалом.
Проверил расчёты в среде Gazebo (научился вставлять параметры правильно)

Студент получает от нейронки два лога, один без коррекции, а второй с коррекцией, закидывает их в нейросеть, и расчитывает показатели (отклонения и ошибки), на основе полученных данных делает вывод, что коррекция по маркерам работает.

Студенту нужно объяснить код одного из полетных заданий - то есть он ознакомится командами библиотеки DroneKit.

Студент исправляет ошибки кода полетных заданий, получает объяснения почему код не работал.
