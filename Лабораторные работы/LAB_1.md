# Лабораторная работа №1 "Оптимизация маршрута доставки квадрокоптером с учётом ограничений по заряду аккумулятора"

## Описание проекта

Проект посвящён моделированию автономной доставки грузов беспилотным летательным аппаратом в условиях ограниченного заряда аккумулятора. Основная задача заключается в разработке алгоритма планирования оптимального маршрута, минимизирующего общее время выполнения миссии за счёт рационального выбора порядка обхода площадок и моментов возврата на зарядную станцию.

Квадрокоптер располагается на стартовой позиции (базе), которая одновременно является зарядной станцией. На полигоне размещены площадки доставки с заранее известными координатами. БПЛА должен последовательно посетить все площадки и вернуться на базу. При этом ёмкость аккумулятора ограничена, а расход заряда пропорционален пройденному расстоянию. При снижении заряда до критического уровня требуется возврат на базу для подзарядки.

Проект демонстрирует подход к решению задачи коммивояжёра с дополнительными ограничениями ресурсного типа в применении к автономным БПЛА.

## Цель проекта

Разработать алгоритм автономного полёта квадрокоптера, реализующий оптимизацию маршрута доставки в условиях ограничения по заряду аккумулятора с минимизацией общего времени выполнения миссии.

## Основная идея

Квадрокоптер выполняет миссию по доставке грузов в условиях ограниченного заряда аккумулятора. Перед началом полёта на основе координат площадок и параметров энергопотребления строится план миссии, определяющий порядок обхода и моменты возврата на базу для подзарядки.

Ключевыми факторами, влияющими на эффективность миссии, являются: порядок посещения площадок, число и моменты подзарядок, а также соблюдение минимального резерва заряда. Чем рациональнее построен маршрут, тем меньше общее время миссии при сохранении её корректности.

Качество разработанного алгоритма оценивается по отклонению фактического времени выполнения миссии от эталонного значения, заранее вычисленного преподавателем.

## Модель расхода энергии

Расход энергии аккумулятора при перелёте между точками определяется пройденным расстоянием:

```text
E_used = k * L
```

где:

- `E_used` — потраченный заряд аккумулятора, у. е.;
- `k` — коэффициент расхода (1 у. е./м);
- `L` — расстояние между точками, м.

Расстояние между двумя точками вычисляется по формуле:

```text
L = sqrt((x2 - x1)^2 + (y2 - y1)^2)
```

Текущий заряд после перелёта:

```text
E(t+1) = E(t) - k * L
```

Условие необходимости возврата на базу для подзарядки:

```text
E(t) - k * (L_to_next + L_next_to_base) < E_reserve
```

где:

- `L_to_next` — расстояние до следующей запланированной площадки;
- `L_next_to_base` — расстояние от этой площадки до базы;
- `E_reserve` — минимальный резерв заряда (10 у. е.).

Пример расчёта. Перелёт «База → Площадка C» на расстоянии 63,2 м потребует:

```text
E_used = 1 * 63.2 = 63.2 у. е.
```

После такого перелёта заряд составит:

```text
E = 100 - 63.2 = 36.8 у. е.
```

## Модель времени выполнения миссии

Общее время миссии складывается из трёх составляющих:

```text
T_total = T_flight + T_landing + T_charge
```

где:

- `T_flight` — суммарное время полёта между всеми точками;
- `T_landing` — суммарное время посадок на площадках;
- `T_charge` — суммарное время подзарядок.

Время полёта между точками:

```text
T_flight = (1 / v) * Σ L_i
```

где `v` — скорость полёта (5 м/с), `L_i` — длина i-го отрезка маршрута.

Время посадок:

```text
T_landing = N_pads * t_landing
```

где `N_pads` — количество площадок (5), `t_landing` — время одной посадки (5 с).

Время подзарядок:

```text
T_charge = N_charge * t_charge
```

где `N_charge` — количество подзарядок, `t_charge` — время полной зарядки (30 с).

## Алгоритм планирования

При разработке алгоритма планирования рекомендуется придерживаться следующей структуры.

### Этап 1. Построение матрицы расстояний

Между всеми парами точек (база и площадки) вычисляются евклидовы расстояния. Результат сохраняется в виде квадратной матрицы размером (N+1) × (N+1).

### Этап 2. Поиск порядка обхода

Применяется один из методов решения задачи коммивояжёра:

- жадный алгоритм (выбор ближайшей непосещённой точки);
- метод полного перебора перестановок (для N ≤ 7 является вычислительно допустимым);
- эвристический метод 2-opt (последовательная оптимизация маршрута заменой пар рёбер).

### Этап 3. Учёт ограничений по заряду

Для выбранной последовательности обхода выполняется симуляция расхода заряда. Если перед очередным перелётом обнаруживается, что заряда недостаточно для безопасного достижения площадки и последующего возврата на базу, в маршрут добавляется промежуточный возврат для подзарядки.

### Этап 4. Расчёт времени

Для итогового маршрута вычисляется общее время выполнения миссии. Среди рассмотренных вариантов выбирается решение с минимальным временем.

## Метрики оценки

Для количественной оценки качества разработанного алгоритма используются следующие метрики.

### Общее время выполнения миссии

```text
T_total = T_flight + T_landing + T_charge
```

### Отклонение времени от эталона

```text
δT = T_actual / T_optimal
```

где:

- `T_actual` — фактическое время выполнения миссии студентом;
- `T_optimal` — эталонное время, полученное преподавателем.

### Длина пройденного маршрута

```text
L_total = Σ L_i
```

### Количество подзарядок

```text
N_charge = количество_возвратов_на_базу_для_зарядки
```

### Минимальный заряд за миссию

```text
E_min = min(E(t))
```

Условие безопасности миссии:

```text
E_min ≥ E_reserve
```

## Критерии оценивания

Основным критерием оценивания результатов работы является отношение фактического времени выполнения миссии к эталонному.

| Отношение T_actual / T_optimal | Оценка |
|---|---|
| ≤ 1,05 | Отлично |
| 1,05 < δT ≤ 1,20 | Хорошо |
| 1,20 < δT ≤ 1,50 | Удовлетворительно |
| δT > 1,50 | Неудовлетворительно |

Дополнительные критерии:

- корректность выполнения миссии (посещение всех площадок, отсутствие нарушения резерва заряда);
- качество исходного кода (структурированность, наличие комментариев, обработка исключительных ситуаций);
- полнота и научная обоснованность отчёта о проделанной работе.

При выявлении нарушения ограничения по минимальному резерву заряда или непосещения хотя бы одной площадки работа считается невыполненной независимо от достигнутого времени миссии.

## Вывод

Решение задачи планирования маршрута квадрокоптера с учётом ограничений по заряду аккумулятора требует одновременного учёта пространственного расположения площадок и энергетических ограничений. Корректное планирование предполагает обязательную проверку достаточности заряда перед каждым перелётом и возврат на базу для подзарядки при снижении энергии до критического уровня.

Качество разработанного алгоритма характеризуется отношением фактического времени выполнения миссии к эталонному. Применение методов оптимизации (полный перебор перестановок, эвристика 2-opt) позволяет приблизить полученное время к оптимальному за счёт рационального выбора порядка обхода площадок и моментов подзарядки.

Ожидается, что разработанный алгоритм обеспечит выполнение миссии с отклонением от эталонного времени не более 5–20% при условии соблюдения всех ограничений по заряду аккумулятора.
