# Решение Лабораторная работа №1 "Оптимизация маршрута доставки квадрокоптером с учётом ограничений по заряду аккумулятора"

## Описание решения
Студенту надо будет самому вставить файлы с кодом в среду Gazebo, работать с терминалом

Проверить расчёты в среде Gazebo (научился вставлять параметры правильно)

Студент научился анализировать поведение модели и находить причины отклонений между теорией и экспериментом

Студент ознакомился с алгоритмами оптимизации полета, выбрал тот у которого было больше преимуществ и наименьшее время полета.

Студенту нужно объяснить код - то есть он ознакомится командами библиотеки DroneKit.

Студент научился проводить вычислительный эксперимент (менять параметр емкости аккумулятора) и анализировать влияние параметров на результат.

Запускает миссию 5-10 раз, фиксирует фактическое время каждой, наблюдает отличия, узнает причины отклонения
