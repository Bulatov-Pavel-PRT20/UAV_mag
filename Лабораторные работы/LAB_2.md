# Лабораторная работ №2 "Оценка и коррекция траектории БПЛА по визуальным меткам ArUco"

## Описание проекта

Проект посвящен моделированию автономного полета беспилотного летательного аппарата по заданной траектории в условиях навигационного дрейфа и внешних возмущений. Основная задача заключается в оценке отклонения БПЛА от эталонного маршрута и коррекции накопленной ошибки с использованием визуальных меток ArUco.

БПЛА выполняет полет по заранее заданному waypoint-маршруту. В процессе движения в навигационные данные искусственно добавляется ошибка, имитирующая дрейф GPS/IMU или накопление ошибки одометрии. На маршруте размещаются ArUco-метки, координаты которых заранее известны. При обнаружении такой метки система уточняет текущее положение БПЛА и корректирует дальнейшее движение.

Проект демонстрирует подход к повышению устойчивости автономной навигации в условиях снижения точности сенсорных данных.

## Цель проекта

Разработать алгоритм автономного полета БПЛА по заданной траектории с использованием визуальных меток ArUco для коррекции навигационной ошибки в условиях имитации дрейфа и внешних возмущений.

## Основная идея

В проекте сравниваются два режима полета:

1. Полет по waypoint-маршруту без визуальной коррекции.
2. Полет по waypoint-маршруту с коррекцией положения по ArUco-меткам.

В первом режиме БПЛА использует только навигационные данные, содержащие искусственно заданный дрейф. Из-за этого ошибка отклонения от маршрута постепенно увеличивается.

Во втором режиме БПЛА дополнительно использует визуальные метки ArUco как опорные точки. При обнаружении метки выполняется уточнение текущей оценки положения, что позволяет уменьшить накопленную ошибку и повысить точность следования заданной траектории.

## Модель навигационной ошибки

Для имитации деградации навигации в координаты БПЛА добавляется систематический дрейф и случайный шум.

```text
x_est(t) = x(t) + dx(t) + nx(t)
y_est(t) = y(t) + dy(t) + ny(t)
```

где:

- `x(t), y(t)` — истинные координаты БПЛА;
- `x_est(t), y_est(t)` — координаты, используемые системой управления;
- `dx(t), dy(t)` — систематический дрейф;
- `nx(t), ny(t)` — случайный шум измерений.

Параметры дрейфа:

```text
dx(t) = 0.02 * t
dy(t) = 0.015 * t
```

Случайный шум:

```text
nx(t), ny(t) ∈ [-0.1; 0.1] м
```

Через 60 секунд полета систематическая ошибка может составить:

```text
dx(60) = 0.02 * 60 = 1.2 м
dy(60) = 0.015 * 60 = 0.9 м
e(60) = sqrt(1.2^2 + 0.9^2) = 1.5 м
```

## Коррекция по ArUco

При обнаружении ArUco-метки система определяет ее идентификатор и относительное положение камеры относительно метки. Так как координаты метки в мировой системе координат известны заранее, система получает уточненную оценку положения БПЛА.

Коррекция выполняется как взвешенное среднее между текущей навигационной оценкой и оценкой, полученной по визуальной метке:

```text
x_corr(t) = α * x_est(t) + (1 - α) * x_aruco(t)
y_corr(t) = α * y_est(t) + (1 - α) * y_aruco(t)
```

где:

- `x_corr(t), y_corr(t)` — скорректированные координаты БПЛА;
- `x_est(t), y_est(t)` — текущая навигационная оценка;
- `x_aruco(t), y_aruco(t)` — оценка положения по ArUco-метке;
- `α` — коэффициент доверия к навигационной системе.

В базовом варианте используется:

```text
α = 0.4
```

Это означает, что 40% веса отводится текущей навигационной оценке, а 60% — визуальной коррекции по ArUco.

Пример:

```text
x_est = 15.8 м
x_aruco = 15.1 м
α = 0.4

x_corr = 0.4 * 15.8 + 0.6 * 15.1 = 15.38 м
```

## Метрики оценки

Для оценки качества движения БПЛА используются следующие метрики.

### Мгновенная ошибка отклонения от маршрута

```text
e_i = sqrt((x_i - x_ref_i)^2 + (y_i - y_ref_i)^2)
```

### Среднеквадратичная ошибка RMSE

```text
RMSE = sqrt((1 / N) * Σ(e_i^2))
```

### Максимальное отклонение

```text
e_max = max(e_i)
```

### Средняя ошибка

```text
e_avg = (1 / N) * Σ(e_i)
```

### Длина фактической траектории

```text
L = Σ sqrt((x_{i+1} - x_i)^2 + (y_{i+1} - y_i)^2)
```

### Время восстановления после коррекции

```text
T_restore = t_restore - t_detect
```

Восстановлением считается момент, когда ошибка становится меньше заданного порога:

```text
e_i < 0.5 м
```

## Результат проекта

Результатом проекта является алгоритм автономного полета БПЛА по заданному маршруту с возможностью коррекции навигационной ошибки по визуальным меткам ArUco.

В ходе эксперимента должны быть получены:

- лог полета БПЛА;
- график эталонной и фактической траектории;
- график изменения ошибки во времени;
- таблица метрик для режима без коррекции;
- таблица метрик для режима с ArUco-коррекцией;
- вывод о влиянии визуальной коррекции на точность автономного полета.

## Вывод

Использование ArUco-меток позволяет уменьшить накопленную навигационную ошибку и повысить точность следования БПЛА заданной траектории. В режиме без коррекции ошибка постепенно возрастает из-за дрейфа GPS/IMU и случайного шума измерений. В режиме с визуальной коррекцией ошибка периодически уменьшается при обнаружении меток, что позволяет БПЛА точнее удерживать заданный маршрут.

Ожидается, что применение ArUco-коррекции позволит снизить RMSE примерно в 2–3 раза, уменьшить максимальное отклонение от маршрута и сократить разницу между фактической и идеальной длиной траектории.
